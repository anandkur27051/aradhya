# JARVIS APK

This repository contains the fixed JARVIS Android APK.

## Installation

1. Download `apk/JARVIS-fixed.apk` from the repository.
2. If an older JARVIS build is installed, uninstall it first.
3. Enable installation from this source when Android asks.
4. Install the downloaded APK.

The original APK was missing a valid Android signing certificate. This build has been signed so Android can install it.
